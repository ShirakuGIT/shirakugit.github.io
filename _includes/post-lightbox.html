{%- comment -%} Shared image lightbox for post and note pages. Mirrors the photography lightbox (prev/next, keyboard nav, click backdrop to close). Any clickable in .post-content / .note-content opens it. Images inside anchors, marked data-no-lightbox, or tiny inline icons (<= 80px tall) are skipped. NOTE: emitted WITHOUT {::nomarkdown} guards. This include is referenced from post.html / note.html LAYOUTS, which are not parsed by kramdown — only {{ content }} (the markdown) is.
