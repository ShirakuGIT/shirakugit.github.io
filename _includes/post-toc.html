{%- comment -%} Scrollspy table-of-contents + reading progress for posts and notes. Two presentations from one data source, fully owned by CSS media queries: - Desktop (>= 1024px): quiet fixed text rail on the right margin. - Mobile (< 1024px): floating bottom-right button opening a native slide-up sheet. showModal()/close() toggle the [open] attribute; CSS hides the sheet entirely on desktop so a resize from mobile->desktop can never leak it. Auto-disabled (data-hidden) when the page has fewer than 3 H1–H4 sections inside .post-content / .note-content. The post title H1 lives in the header (not a child of .post-content), so it's excluded naturally. Output is compact HTML — no {::nomarkdown} guards — because this include is referenced from HTML layouts where kramdown directives would leak as literal text. {%- endcomment -%}
